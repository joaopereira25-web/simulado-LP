# Simulado Online de Língua Portuguesa

Este site está preparado para publicação no GitHub Pages.

## Como publicar
1. Entre em https://github.com/new
2. Crie um repositório público com o nome `simulado-lingua-portuguesa`.
3. Envie o arquivo `index.html` deste pacote para a raiz do repositório (Add file > Upload files > Commit changes).
4. Abra Settings > Pages.
5. Em Build and deployment, escolha Deploy from a branch.
6. Selecione a branch `main` e a pasta `/(root)`; clique em Save.
7. Aguarde a publicação. O endereço costuma seguir o formato:
   https://SEU-USUARIO.github.io/simulado-lingua-portuguesa/

Substitua `SEU-USUARIO` pelo nome de usuário do GitHub. Confirme o endereço final na seção Settings > Pages.

## Observações
- O simulado corrige as respostas no próprio navegador.
- Esta versão não envia nem salva as notas dos estudantes em uma planilha ou banco de dados.
- Gere o QR Code somente depois de confirmar que o endereço público abre corretamente.
